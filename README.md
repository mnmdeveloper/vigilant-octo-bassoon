# vigilant-octo-bassoon

## Сервер и мастер настройки

Для Linux-сервера с Docker Compose:

```sh
git clone git@github.com:mnmdeveloper/vigilant-octo-bassoon.git
cd vigilant-octo-bassoon
python3 setup_server.py
docker compose up -d --build
```

Мастер запросит токен BotFather, ID администратора и необязательные API-ключи. Секреты вводятся скрыто и сохраняются локально в `.env`, исключённом из Git. Используйте отдельного бота для этого сервиса. API-ключи нужны для создания новых сессий; импорт готовых Pyrofork-сессий работает без них.

Логи: `docker compose logs -f --tail=100`. Остановка: `docker compose down`. Обновление: `git pull`, затем `docker compose up -d --build`. Каталог `data` хранит аккаунты, аудио и задания между перезапусками. Не запускайте одновременно несколько экземпляров с одним токеном.

На Ubuntu/Debian без Docker установите Python 3.11, venv и FFmpeg, затем выполните `sh install_server.sh`. Этот вариант запускается командой `.venv/bin/python -m app.main` и требует отдельного менеджера процессов для постоянной работы. На Windows мастер доступен через `.venv\Scripts\python.exe setup_server.py`, запуск — `start.cmd`.

Для переноса с Windows остановите старый экземпляр и импортируйте `.session` и аудио на сервер заново: сохранённые абсолютные Windows-пути в базе не подходят Linux. Существующие задания эфиров не переносите без проверки путей. Часовой пояс планирования — МСК.

# Telegram promo assistant

Локальный Python-бот для управления одним или несколькими пользовательскими Telegram-аккаунтами на Windows.

## Подключение без API-ключей

Для создания новой сессии в боте заполните API-ключи в `.env`, перезапустите приложение и нажмите `🔐 Создать сессию`. Введите номер, затем код вручную с пробелами между цифрами; при включённой 2FA введите облачный пароль. Сессия Pyrofork создаётся в `data/sessions` и автоматически применяется к аккаунту. Пароль и код не сохраняются в базе. `/cancel` отменяет вход и удаляет незавершённую локальную сессию.

Для уже авторизованной сессии Pyrogram/Pyrofork достаточно заполнить `BOT_TOKEN` и `ADMIN_ID` в `.env`. Поля `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` можно оставить пустыми.

Запустите `start.cmd`, отправьте `/start` и нажмите `📂 Импорт .session`. Введите полный путь, например `D:\Funpay-Telegram-Gifts\sessions\stars.session`. Приложение создаст отдельную копию; исходный файл не изменяется. Также можно отправить сессию документом в приватный чат админ-бота. Файл даёт доступ к аккаунту — предпочтителен локальный путь.

Поддерживаются авторизованные пользовательские SQLite-сессии Pyrogram/Pyrofork. Telethon `.session`, StringSession и `tdata` через эту кнопку не импортируются. Существующие подключения Telethon сохранены; для них и для нового входа по номеру API-ключи всё ещё требуются. Подключение через файл не отключает звонки; их обработчик использует PyTgCalls с Pyrogram bridge. Перед использованием проверьте реальный звонок со второго аккаунта.

Возможности:

- авторизовать пользовательский аккаунт по номеру, коду и 2FA-паролю;
- показать каналы и супергруппы, доступные аккаунту;
- создать текстовый пост или пост с одной картинкой;
- постоянно сохранять людей, которые пишут подключённому аккаунту;
- перед отправкой дополнительно проверить последние 100 сообщений личных диалогов;
- отправить пост только этим пользователям;
- делать паузу между отправками и прекращать работу при `FloodWait`;
- хранить историю отправок;
- принять входящий личный Telegram-звонок, воспроизвести выбранное аудио и завершить звонок после окончания файла;
- включать автоответ отдельно для каждого аккаунта.

## Ограничения

## Аудитории и голосовые

После создания поста или отправки voice-сообщения боту выберите аккаунт, затем аудиторию: писавшие, звонившие или обе группы. Звонящие записываются с момента работы сервиса, включая звонки при выключенном автоответе. Старая история звонков автоматически не импортируется.

Через `➕ Добавить канал` зарегистрируйте @username или ID канала, где админ-бот имеет права администратора. Канал появится в выборе аудитории. Подписка проверяется перед отправкой среди известных писавших и звонивших выбранному аккаунту. Это не выгрузка полного списка подписчиков. Если Telegram ограничит проверку, отправка прекращается с сообщением о необходимой паузе.

Для голосовой рассылки отправьте боту voice-сообщение при создании поста. Оно отправляется получателям как голосовое; обычный MP3-документ через этот сценарий не преобразуется автоматически.

Обычный Telegram Bot API не выдаёт список подписчиков канала. Пользовательский API иногда позволяет видеть участников групп, но не гарантирует полный список подписчиков каналов, а нежелательные массовые личные сообщения нарушают правила Telegram и приводят к блокировке. Поэтому приложение не рассылает сообщения по участникам канала.

Автоответ на звонки работает через нативные библиотеки `PyTgCalls`/`NTgCalls` и FFmpeg. Это более чувствительная к обновлениям Telegram часть приложения. ПК и программа должны быть включены, аккаунт должен разрешать звонки от нужных пользователей, а Windows должна разрешать программе доступ к сети.

## Быстрая установка на Windows

Дважды нажмите `install.cmd`. Установщик:

- установит Python 3.11 через `winget`, если его нет;
- создаст `.venv`;
- установит все Python-библиотеки, включая нативный VoIP-модуль;
- установит FFmpeg через `winget`;
- создаст и откроет `.env`.

После заполнения `.env` запустите `start.cmd`.

Установщик совместим с Windows PowerShell 5.1. Для проверки библиотек и FFmpeg без подключения к Telegram выполните `.venv\Scripts\python.exe -m app.doctor`.

Проверка зависимостей и аудиофайла не подтверждает передачу звука в реальном звонке. После настройки проверьте автоответ звонком со второго аккаунта и отправкой поста в тестовый диалог.

## Ручная установка

1. Установите Python 3.11 x64.
2. Создайте бота через `@BotFather`.
3. Узнайте свой числовой Telegram ID (например, через `@userinfobot`).
4. Создайте API-приложение на <https://my.telegram.org/apps> и получите `api_id` и `api_hash`.
5. В PowerShell из папки проекта выполните:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

6. Установите FFmpeg и убедитесь, что команды `ffmpeg` и `ffprobe` доступны в новом окне PowerShell.
7. Заполните `.env`, затем запустите:

```powershell
python -m app.main
```

Напишите своему боту `/start`. Файл `data/app.sqlite3` содержит Telegram-сессии, поэтому не публикуйте его и не отправляйте другим людям. Загруженное аудио хранится в `data/audio`.

## Работа со звонками

## Запланированные трансляции

Добавьте канал в админ-боте и подключите пользовательский аккаунт Pyrofork, у которого есть право управления трансляциями в этом канале. Загрузите аудио через «Настроить звонки» (включать автоответ для эфира не требуется). Нажмите «📅 Запланировать эфир», выберите аккаунт, канал и дату в формате `ДД.ММ.ГГГГ ЧЧ:ММ` по московскому времени — МСК (UTC+3, Europe/Moscow), затем подтвердите создание.

Telegram разрешает планирование до 8 дней вперёд. Программа должна работать и иметь интернет в назначенное время. После окончания аудиопотока выдерживается 5 секунд и эфир завершается. Задания хранятся в SQLite; просроченные запланированные эфиры запускаются после включения программы. Эфир, прерванный остановкой программы, закрывается при следующем запуске и не проигрывается заново.

Участники входят с выключенным микрофоном; программа заглушает остальных выступающих. Обычные участники принудительно заглушаются, однако Telegram позволяет другим администраторам самостоятельно включить микрофон. Для режима только одного выступающего не выдавайте другим участникам право управления трансляциями. Уже существующий эфир в канале не заменяется.

1. Добавьте пользовательский аккаунт.
2. Откройте `☎️ Настроить звонки`.
3. Выберите аккаунт и загрузите MP3, WAV, OGG, M4A или другой формат, который читает FFmpeg.
4. Нажмите `▶️ Включить автоответ`.
5. Оставьте `start.cmd` запущенным.

При выключенном автоответе приложение не вмешивается в звонок — он продолжит звонить на других ваших устройствах. При включённом — принимает, проигрывает файл и завершает звонок.

## Безопасность

Бот не выполняет команды пользователей, кроме `ADMIN_ID`. Код и 2FA-пароль удаляются из чата сразу после чтения и не записываются в базу. Для реального использования рекомендуется хранить базу на зашифрованном диске и отдельно добавить шифрование сессий.
